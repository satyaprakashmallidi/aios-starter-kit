- `outreach/templates/` — Customize message templates

## How It Works

1. **You** find leads from LinkedIn, referrals, or any source
2. **You** give the list to Claude with `/start-outreach`
3. **Claude** triggers your WhatsApp n8n workflow → sends personalized messages
4. **Claude** logs each lead to Bitrix24 automatically
5. **3 days later** — if no reply, Claude reminds you to send Gmail follow-ups
6. **You** manage conversations → deals close
